# South Cebu Freelancers Club photos

Photos for the "South Cebu Freelancers Club" section on `events.html` live here.

- `club-1.jpg` through `club-6.jpg`

Tips:
- Currently sized to fit a 1:1 square tile, so square or center-croppable photos
  from meetups work best.
- Keep each file under ~300KB (export as JPG, "web quality" ~70-80%) so the page
  stays fast to load.
- Want more than 6? Add `club-7.jpg`, etc., and add a matching
  `<img src="/public/club/club-7.jpg" ...>` line in the club section of `events.html`.
- Until a file exists at one of these paths, that tile is skipped automatically (no broken-image icon).
